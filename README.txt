# Proyecto de Sistemas Inteligentes

## Simon Dice Inteligente con ESP32-S3

### Descripción general

Este repositorio contiene la documentación, diagramas, código fuente y evidencias del proyecto **Simon Dice Inteligente**, desarrollado para la asignatura **Sistemas Inteligentes**.

El proyecto consiste en la implementación de un sistema interactivo basado en **ESP32-S3**, programado en **MicroPython**, capaz de reproducir secuencias visuales que el usuario debe repetir mediante botones físicos. El sistema incorpora además **pantalla OLED**, **LEDs de retroalimentación** y un mecanismo de **activación por sonido o por botón**, organizado mediante una **máquina de estados**.

### Estructura del repositorio

* **01_Documentacion**: memoria técnica, propuesta de valor, manual y documentos formales.
* **02_Diagramas**: diagramas de caso de uso, flujo, actividad y UML.
* **03_Codigo_fuente**: proyecto base en MicroPython para ESP32-S3.
* **04_Evidencias**: imágenes y material visual del prototipo.
* **05_Identidad**: logotipo institucional y apoyo visual.

### Tecnologías y herramientas utilizadas

* ESP32-S3
* MicroPython
* Thonny
* Visual Studio Code
* Pantalla OLED SSD1306
* Botones, LEDs y protoboard

### Objetivo del proyecto

Diseñar e implementar un prototipo funcional del juego Simon Dice utilizando una arquitectura modular de hardware y software, integrando entradas físicas, salidas visuales y lógica de validación secuencial.

### Estado del proyecto

Proyecto funcional y documentado con fines académicos.
